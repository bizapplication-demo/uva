# 变更 2026-11-09 · M1 骨架 + M2 模拟闭环第一切

## 目标
按文字稿 v0.2（`docs/` 副本，真源在 goals/uva）交付可本地运行的 MVP 第一版：仓库骨架、schema/seed、登录、态势页活起来、模拟引擎 1Hz 闭环、其余页签可用版。

## 实现选择与理由（与 §7 的偏离，明说）

| 项 | §7 口径 | 本版实现 | 理由 |
|---|---|---|---|
| 依赖 | Fastify + better-sqlite3、Vue3+Vite+Leaflet、pnpm workspace 两包 | **零外部依赖**：仅 Node 内置模块（node:http / node:sqlite / node:crypto）+ 原生 HTML/CSS/JS，单包单进程 | 本机 personal-system 已验证零依赖路线；离线可跑、无供应链与构建步骤、部署只需一个 node 进程。API 契约（`/uva/api/v1/*`、响应结构）与 §7 保持一致，Vue/Leaflet 化时只换前端、后端不动 |
| 实时通道 | WebSocket `/uva/ws` | **SSE** `/uva/api/v1/stream`（每秒 telemetry + 即时 event） | 遥测是单向推送场景，SSE 用内置 http 即可、免 ws 协议实现；EventSource 不能带 header，故 stream 支持 `?token=`。后续如需双向控制通道再加 WS |
| 地图 | Leaflet + 瓦片 | canvas 自绘（网格/抽象道路水体/围栏/航线/尾迹） | 零依赖且离线可用；演示区为虚构坐标，本不需要真实瓦片。Leaflet 化列后续 |
| 密码/鉴权 | bcrypt + JWT | scrypt（node:crypto）哈希 + 服务端 session token（720 分钟） | 零依赖下等价安全口径；token 语义与 JWT 一致，前端无感 |
| 部署形态 | A：Node 同进程托管静态文件 | 同 A，基础路径 `/uva/`，页面与 API 同前缀 | 与最终 `app.outofwork.cn/uva` + `api.outofwork.cn/uva` 的差异仅在 nginx 分流，代码不感知 |

Vue 化列为后续里程碑（M3 之后评估）：触发条件为页面复杂度超出原生维护成本，或需要与 EIS 前端逐项对照时。

## 本版交付
- 数据层：`db/schema.sql`（orgs/users/devices/docks/waylines/missions/flights/alerts/fences/media/audit_logs + sessions）；`db/seed.js` 种子——1 组织、6 成员、3 机巢、6 无人机、3 航线、10 任务（flying/ready/completed/failed/timeout/draft）、5 告警、围栏三类（限飞红/任务黄/区域白）、执行记录 34 条。全部模拟，虚构「惠州演示区」，编号 `UVA-DEMO-*`。
- 模拟引擎 `src/simulator.js`：1Hz tick，flying 任务沿航点插值移动、电量下降、走完一圈判完成→写飞行记录→自动进入下一轮（演示持续有在飞对象）；30%/20% 电量与围栏接近注入告警/事件；状态经 `/simulator` 与 overview 可查。
- API：login / overview / devices / docks / missions / alerts(+ack) / records / fences / waylines / org/members / assistant（规则问答，查真实 DB）/ stream(SSE)。写操作仅确认告警与助理对话。响应统一带 `simulated:true`。
- 前端（Palantir 式深色指挥风，令牌见 style.css：底 #0b0e13/#10151d、细边框、无大圆角、12–13px、mono 数字、绿/琥珀/红/冷蓝）：
  - 页签工作台：左图标栏 + 顶部可关闭页签（8 模块），态势默认开。
  - 态势页：顶栏（UVA 标志/组织下拉/头像组/秒级时钟/告警计数/全屏/模拟角标+数据时间）、左 AI 助理面板（5 快捷提示 + 输入，均调 assistant API）、中央 canvas 地图（实时移动+尾迹+点击选中）、右侧四段（追踪/设备/直播/任务）+ 本体详情卡（含驾驶舱模拟回执）、底部事件流。
  - 超越清单落地：①直播窗 canvas 动画（扫描线/移动目标/OSD 时间码逐帧动）②遥测真 1Hz（SSE 驱动位置与电量）③列表骨架屏先行 ④设备表列可勾选显隐 ⑤任务规划画布打开即示例方案（航点连线+视野幅宽）。
  - 其余页签可用版：设备中心（飞机/机巢子页签+列显隐）、媒体中心（执行记录表+轨迹回放滑杆）、消息中心（告警表+确认）、用户中心（成员表）、项目中心（项目卡）、智能搜索（描述→模拟命中卡）。

## 自测证据（2026-11-09 本地实测，Node v24.22.1）

启动：`PORT=8734 node src/server.js` → `UVA listening on http://127.0.0.1:8734/uva/`

```bash
curl /uva/api/v1/health            # 200 {ok:true, simulated:true, simulator:{running:true, hz:1}}
curl -X POST /uva/api/v1/login {demo/uva-demo}   # 200, token 长度 48
curl /uva/api/v1/overview (Bearer) # devicesTotal=6, devicesFlying=2, docksTotal=3, missionsToday=10,
                                   # missionsFlying=2, alertsOpen=4, flightsTotal=34, 低电量清单 2 架
curl /uva/api/v1/devices           # 6 条; 二次采样坐标已偏移（模拟引擎在推进）
curl -X POST /uva/api/v1/assistant {"message":"低电量处理建议"}
                                   # 答: 低电量 2 架（巡检二号 28%、备勤一号 15%）——查真实 DB
curl /uva/                         # HTML 200; app.js/style.css 均 200
curl /uva/api/v1/records           # 34 条 (>=30)
curl -X POST /uva/api/v1/alerts/3/ack  # {acked:3}
curl /uva/api/v1/{fences,waylines,org/members,missions,alerts,docks}  # 3/3/6/10/5/3 条
curl 无 token /uva/api/v1/devices  # 401（鉴权生效）
node --check 全部 JS 文件          # SYNTAX OK
node test/smoke.js                 # 7 passed, 0 failed（含 SSE: 3.5 秒收到 3 条 telemetry >= 2）
```

自测后已关闭服务进程、删除运行时 `data/uva.db*`（gitignore 内），下次 `npm start` 自动重建种子。
