## 1. 定位（一句话）
一个前端体验超越道通 EIS、后台刻意轻量的无人机智能指挥系统高仿版：
中央是活的态势地图，围绕它组织设备、任务、告警与复盘；所有数据均为模拟，
但交互、信息密度与视觉秩序按真实指挥系统标准做。

- 对标：道通 EIS（天盾/SkyShield）——接入→任务→监控→控制→复盘全流程 + AI 语音助理
- 超越点：前端体验。借鉴 Palantir Gotham/Foundry 的指挥界面语言（见 §6）
- 不做：真实设备接入、真实飞控、真实视频推流、微服务/K8s、多区域部署
- 开发方式：完全由 AI 开发；代码进 GitHub，一应用一仓库

## 2. 入口与平台约定（app 平台总规，UVA 是第一个实例）
- 前端：https://app.outofwork.cn/uva/        （静态 SPA，同域子路径）
- 后端：https://api.outofwork.cn/uva/        （REST + WebSocket，同前缀）
  注：用户口头写的 api.outofwork/uva 按 api.outofwork.cn 理解，待确认。
- 仓库：https://github.com/bizapplication-demo/uva （组织 bizapplication-demo，企业业务应用示例）
- 后续应用同模式：/pm → 仓库 pm，/crm → 仓库 crm；每个应用独立仓库、独立部署、独立 SQLite
- 平台层只共享三样：登录口径（后续统一）、设计令牌、部署脚本模板；业务代码不共享、不做 monorepo

## 3. 从 EIS 借什么、砍什么
EIS 原系统（据逆向架构说明书 ai.7x24.work/products/eis/arch/，2026-10-31）：
6+1 仓库、9814 提交、43 个业务领域包、5 个 Spring Cloud 微服务、Nacos/PG/Redis/EMQX/SRS、
Cesium 三维地图、MQTT 遥测、WebRTC 视频、豆包 ASR/LLM。

UVA 的取舍：
| EIS 能力 | UVA 处理 | 方式 |
|---|---|---|
| 三维/二维态势地图 | 保留，核心页 | 2D 先行（Leaflet+国内瓦片/离线风格底图），轨迹/围栏/视锥用图层模拟；3D 列二期 |
| 设备/机场台账 | 保留 | SQLite 表 + 模拟遥测引擎定时推进 |
| 航线/任务规划与下发 | 保留（模拟下发） | 航点编辑、任务状态机、模拟执行进度 |
| 飞行监控 OSD/轨迹/告警 | 保留 | WebSocket 1Hz 推送模拟遥测，前端实时渲染 |
| 远程控制（起降/云台） | 只做 UI + 模拟回执 | 按钮可点、后端模拟 ACK，明确标注「模拟」 |
| 视频直播/回放 | 占位超越 | 视频窗用模拟画面/巡检图轮播 + OSD 叠加，不接真实流 |
| 电子围栏 | 保留 | 地图多边形绘制 + 越界模拟告警 |
| AI 语音/助理 | 保留为文字助理 v1 | 预置问答/指令解析（本地规则），语音列二期 |
| 组织/RBAC/租户/审计 | 轻量保留 | 单组织、多用户、角色（管理员/飞手/观察员）、操作日志表 |
| 媒体/报告/复盘 | 保留 | 飞行记录、轨迹回放、任务报告自动生成 |
| 微服务/Nacos/K8s/EMQX | 全部砍掉 | 单体 Node 服务一个进程搞定 |
| PostgreSQL/Redis/MinIO | 全部砍掉 | SQLite 一文件；媒体用本地静态文件 |

## 4. 页面清单（实测校准：页签工作台模型，不是左侧菜单树）
EIS 实测导航：极简左栏（态势/主题/设置/头像）+ 顶部页签栏，「新增页签」开出 12 个功能模块，
每个模块是一个可关闭页签。UVA 照此模型，模块清单按实测收敛为 10 个：
1. `/situation` 态势地图（默认首页）——见 §5 详述
2. `/workflow` 任务规划画布：EIS 实测为空白画布（须从助理方案卡打开）；UVA 打开即带示例方案，
   航点/巡检目标/相机视野幅宽可在画布上改，状态机 草稿→待下发→执行中→已完成/异常（模拟下发）
3. `/console` 控制台：EIS 实测无独立页；UVA 不做假页，做成态势页选中设备后的「驾驶舱」面板
   （OSD、云台、起降等按钮 + 模拟回执）
4. `/smart-search` 智能搜索：选素材 + 取帧频率 + 目标描述 → 模拟命中结果（EIS 同名功能）
5. `/media` 媒体中心：媒体库 + 计划执行记录（实测列：时间/计划/项目/状态/飞机/机巢/里程/时长/
   喊话时长/最大高度/耗电/操作[回放、媒体文件]）+ 事件记录；UVA 轨迹回放并入此模块，不单设复盘页
6. `/devices` 设备中心：页签 飞机/机巢/基站/遥控器/侦测反制/机器人（实测飞机 0 条、机巢 11 条）；
   列按实测（型号/在线/区域/双固件/存储/组网/RTK/起降高度/备降点），但 UVA 列可配置显隐
7. `/projects` 项目中心：项目卡片（默认/永久、成员数、创建者、创建时间）+ 项目点位小地图
8. `/alerts` 消息中心：设备告警（时间/等级红黄蓝/型号/类型/设备名/内容）+ 事件通知（实测 0 条）
9. `/org` 用户中心：人员/部门/区域/操作日志/申请记录（实测人员 169 条）+ 角色
10. `/account` 账号设置：账号与安全 + 消息订阅（告警/任务异常/系统事件 × 短信/邮箱开关）
另：AI 助理不单设页——它是态势页默认左面板（见 §5），UVA 同此，另加全局唤起抽屉；
仿真模块 EIS 实测内嵌内网地址加载失败，UVA 不设此页，模拟能力直接长在态势/任务里。

## 5. 态势页布局（实测校准版）
- 顶栏：标志 · 项目下拉 · 切换组织 · 区域成员头像组（带人数）· 秒级时钟 · 告警管理（计数）· 全屏
  UVA 另加：全局搜索（设备/任务/地点）
- 左栏：极简图标栏（态势/主题/设置/头像）；其内侧默认展开 AI 助理面板（实测宽约 440）：
  新会话、快捷提示（智能生成任务/查看机队状态/低电量处理建议/处置中目标）、底部输入框
  （创建任务或提问）+ 语音入口
- 中央：灰度卫星图默认 2D、右下切 3D；图层含干扰区、限飞区（红）、任务区（黄三角）、
  区域多边形（白）、编号点位；右侧竖排地图工具（指北/标记/图层/锁定/限飞区/显示/缩放）
- 右侧综合面板（可收起，四段实测结构）：①追踪（敌方/友方、搜索/筛选）
  ②设备（机巢卡：状态、巢内有无飞机、巢内/巢外双视频窗、「进入设备驾驶舱」）
  ③直播（直播卡：设备名、状态、飞行进度、多路视频流）④任务（设备/批次页签、同步时间、
  任务卡：设备名+时间+状态标签）
  UVA 在此之上加一层：选中任何对象时，右面板顶部出现本体详情卡（属性/实时遥测/关联对象/动作）
- 底栏（UVA 新增，EIS 无）：实时事件流 + 在飞任务迷你进度
- 数据角标硬规矩（沿用用户既定）：所有实时数字标「模拟数据」+ 数据时间 + 来源（模拟引擎）
- 实测到的 EIS 体验短板 = UVA 超越清单：视频窗无法播放 → 模拟画面必须动；遥测是昨日快照 →
  真 1Hz 推进；列表先「0 条」再跳数 → 骨架屏；表格横向长卷 → 列可配置；规划画布空白 → 预置示例

## 6. 视觉规范（Palantir 式，前端超越的抓手）
- 深色指挥风为唯一主题：近黑蓝灰底（#0b0e13 / #10151d）、面板细边框、无大圆角、无渐变装饰
- 高信息密度：小字号（12–13px）、紧行距、等宽数字（遥测/坐标/时间用 mono）
- 语义色克制：正常=低饱和绿、注意=琥珀、告警=红、主操作=冷蓝；其余全部灰阶
- 本体优先：一切对象（机/机场/任务/告警）都有统一详情卡，对象间可跳转关联（图谱感）
- 时间是一等公民：所有面板带时间戳，底部有全局时间轴，复盘可拖动回放
- 动效只服务状态变化：位置平滑移动、告警脉冲、数字跳变；不用装饰性动画
- 与全站设计系统的关系：UVA 是 Work 档的深色特例，令牌单独一套（uva-tokens），不套五域主色

## 7. 技术栈（刻意轻）
- 全仓 TypeScript 优先、单语言 Node 生态；不用 Java/Go/Python 服务
- 后端：Node.js（LTS）+ Fastify（或 Express，二选一在脚手架时定，默认 Fastify）+ better-sqlite3
  - REST：/uva/api/v1/* ；实时：WebSocket /uva/ws（遥测 1Hz、事件即时）
  - 模拟引擎：独立模块 simulator/，按航线推进位置、耗电、告警注入，可暂停/加速
  - 鉴权：JWT（与 EIS 720 分钟口径对齐即可），密码 bcrypt；种子账号开箱即用
- 前端：Vue 3 + Vite（与 EIS 前端同代际，便于对照）+ Leaflet；状态 Pinia；构建产物静态托管
  - 部署形态 A（默认）：前端静态文件由 Node 同进程托管，单服务单端口，nginx 只做反代
- 数据：SQLite 单文件 data/uva.db，建表 SQL 入仓（schema.sql + seed），解决 EIS「schema 不入库」之弊
- 工程：pnpm workspace 两包（apps/api、apps/web）同仓；changes/ 变更文件沿用用户既定规范

## 8. 数据模型（v0.1 草案）
orgs, users, roles；devices（无人机：sn/型号/状态/电量/坐标/固件），docks（机场）；
waylines（航线：航点 JSON），missions（任务：航线/设备/状态机/计划时间），
flights（飞行记录：轨迹 JSON/时长/里程），telemetry（遥测流水，可只留最近 N 条），
alerts（告警：级别/对象/状态），fences（围栏多边形），media（媒体索引），audit_logs，reports
